# Rotine Mobile II

O Rotine é um aplicativo mobile desenvolvido para ajudar usuários a organizar tarefas domésticas, pessoais e compromissos do dia a dia de forma simples, prática e eficiente.

## Visão geral

Este projeto foi pensado para facilitar o gerenciamento de atividades rotineiras, permitindo ao usuário registrar pendências, acompanhar o progresso e manter maior controle sobre sua rotina sem perder organização.

## Funcionalidades

- Cadastro de tarefas diárias e recorrentes
- Organização por categorias ou prioridades
- Acompanhamento do status das atividades
- Interface simples e intuitiva para uso mobile
- Foco em produtividade e organização pessoal

## Tecnologias

- React Native
- Expo
- JavaScript
